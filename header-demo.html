🎨 Diseño Moderno del Header

Este header ha sido cuidadosamente diseñado para reflejar la identidad de This is Fuerteventura: moderno, accesible, y coherente con la belleza natural de la isla. Combina elementos visuales sofisticados con funcionalidad intuitiva, garantizando una experiencia de usuario excepcional en todos los dispositivos.

Scroll hacia abajo para descubrir las características, animaciones, y principios de accesibilidad que hacen que este header sea único.

✨ Características Principales

Responsive Design

Adaptable perfectamente desde móviles (320px) hasta pantallas ultra-wide (1920px+). El hamburger menu se activa automáticamente en tablets.

GSAP Animations

Animaciones fluidas y suaves con GSAP: hover effects, menú desplegable, búsqueda interactiva, y transiciones elegantes que mejoran la experiencia sin saturar.

WCAG AA Accesible

Cumple con estándares WCAG 2.1 AA: contraste suficiente, navegación por teclado, etiquetas ARIA, y anuncio correcto en lectores de pantalla.

Búsqueda Integrada

Barra de búsqueda interactiva con soporte para Ctrl+K. Se expande al hacer clic, permitiendo buscar contenido rápidamente.

Redes Sociales

Enlaces a plataformas sociales con animaciones hover (levantamiento, rotación). Ocultos en móviles pequeños para optimizar espacio.

CTA Prominente

Botón "Explora la Isla" con pulso sutil en carga. Invita a usuarios a descubrir contenido turístico con alta visibilidad y click-through rate.

🎯 Principios de Diseño

El header refleja cinco pilares fundamentales que garantizan coherencia y excelencia:

1. Minimalismo Inteligente

Líneas limpias, espaciado generoso, y jerarquía visual clara. Cada elemento tiene propósito; nada es superficial.

2. Coherencia Visual

Paleta inspirada en Fuerteventura: turquesa (océano), arena dorada, cielo profundo. Colores auténticos que cuentan la historia de la isla.

3. Performance First

CSS optimizado, JavaScript modular, sin dependencias pesadas. Carga rápida incluso en conexiones lentas.

4. Inclusión Digital

Accesible para todos: usuarios con discapacidades visuales, auditivas, motoras. Navegación por teclado fluida.

5. Escalabilidad

Fácil de mantener y expandir. Tokens CSS claros, componentes modulares, documentación completa.

🎬 Animaciones en Acción

← Pasa el ratón sobre el cuadro para ver escala 1.05 + sombra intensa (igual que botón CTA)

Todas las animaciones están diseñadas para ser suaves (0.3s - 0.4s) y elegantes. Si prefieres movimiento reducido, el sistema respeta prefers-reduced-motion.

♿ Accesibilidad Completa

El header cumple con WCAG 2.1 Level AA. Aquí están los detalles:

Criterio Implementación Ratio Contraste
Texto sobre fondo principal #333333 sobre #ffffff 15:1 ✓
Enlaces (turquesa) #2ec4b6 sobre #ffffff 4.5:1 ✓
Botón CTA (turquesa gradient) Blanco sobre #2ec4b6 7.2:1 ✓
Navegación por teclado Tab, Shift+Tab, Enter, ESC N/A ✓
Etiquetas ARIA aria-label, aria-current, aria-expanded N/A ✓

Atajos de Teclado

Atajo Acción
Tab Navegar entre elementos interactivos
Shift+Tab Navegar en reversa
Enter Activar botón o enlace enfocado
ESC Cerrar menú móvil (si está abierto)
Ctrl+K / Cmd+K Activar barra de búsqueda

💻 Estructura de Código

Archivos Creados

  • css/header.css (~450 líneas) - Estilos responsive y animaciones CSS
  • js/components/Header.js (~400 líneas) - Lógica JavaScript con GSAP
  • HEADER.md (~500 líneas) - Documentación completa

Cómo Integrar

<!-- En <head> --> <link rel="stylesheet" href="css/header.css"> <!-- Antes de </body> --> <script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/gsap.min.js"></script> <script src="js/components/Header.js"></script>
