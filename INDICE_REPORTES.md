## 🛠️ HERRAMIENTAS RECOMENDADAS

Para implementar las recomendaciones:

```bash
# Conversión de imágenes
$ brew install webp  # macOS
$ sudo apt install webp  # Linux
$ cwebp image.png -o image.webp -q 80

# Minificación de CSS
$ npm install -g clean-css-cli
$ cleancss css/styles.css -o css/styles.min.css

# Análisis de tamaño
$ du -sh *           # Tamaño por carpeta
$ tree -L 2 -h       # Estructura con tamaños

# Búsqueda de referencias
$ grep -r "archivo" . --include="*.html"
```
